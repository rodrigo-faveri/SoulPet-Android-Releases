# SoulPet para Android

Este repositório público contém somente os arquivos instaláveis das versões de teste do SoulPet.

- O código-fonte do projeto permanece privado.
- Baixe o APK pela seção **Releases**.
- Ao atualizar, instale a nova versão por cima da anterior para preservar os pets salvos.
- Contato: gamesoulpet@gmail.com
